## 转换原则
- Apple 资料提供层级、间距、材质、动效和适应窗口的方向。
- Microsoft 资料定义 Windows/WPF 的控件、模板、性能、DPI 和可访问性约束。
- WPF 工程正确性与 Windows 使用习惯优先于视觉仿制。
