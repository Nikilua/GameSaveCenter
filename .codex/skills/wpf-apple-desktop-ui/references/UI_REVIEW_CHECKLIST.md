# UI 回归检查清单

## 信息架构
- [ ] 当前页面只显示当前模块内容
- [ ] 没有重复导航/状态
- [ ] 主操作明确
- [ ] 技术详情已折叠或放详情区

## 布局
- [ ] 1600×900 / 1366×768 / 1280×720 / 1100×700 / 980×640
- [ ] 无重叠、裁切、无意义大空白
- [ ] Compact 不强制三栏
- [ ] 标题/主要工具栏固定，列表内部滚动

## DPI
- [ ] 100% / 125% / 150% / 200%
- [ ] 图标、圆角、细线、文本、Popup 正常

## 控件
- [ ] Button 同高、图文居中
- [ ] SearchBox Watermark/清除正确
- [ ] ComboBox 默认值与 Popup 主题正确
- [ ] Pill Tab 四角完整，内容 Stretch
- [ ] CheckBox 非系统白方块
- [ ] ScrollBar 两端对称，大数据不变尖点
- [ ] DataGrid 表头不越框，列拖动条不刺眼
- [ ] 横向滚动可访问
- [ ] 状态点/文字同基线
- [ ] 进度条/百分比完整

## 文本
- [ ] 无内部类型名作主文案
- [ ] 长路径可恢复/复制
- [ ] 错误信息用户可理解
- [ ] 选中行文字不变黑
- [ ] 空状态有下一步

## 主题与交互
- [ ] Light / Dark / Follow Host / High Contrast / 透明关闭
- [ ] 无默认白色控件泄漏
- [ ] Keyboard-only 和 Focus Ring
- [ ] Dialog 焦点安全，Toast 不抢焦点
- [ ] 状态不只靠颜色

## 性能与交付
- [ ] List/DataGrid virtualization
- [ ] 无每行 BlurEffect/Timer/布局动画
- [ ] XAML、Build、Tests、验证脚本通过
- [ ] 实际安装版本已核对
- [ ] 未验证项明确说明
