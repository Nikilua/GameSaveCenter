## 4. 公共设计契约与验收口径

### 4.1 排版目标

以下沿用当前字阶，不要求一次性换字体或扩大字号。只有样本对照证明更好且短窗门禁仍通过时才调整。

| 语义 | 当前起点 | 精修重点 |
| --- | --- | --- |
| Display | 28 DIP / SemiBold | 少量展示区域；避免抢占业务首屏 |
| 页面标题 | 22 DIP / SemiBold | 中英标题视觉重量接近，基线稳定 |
| 区块标题 | 16 DIP / SemiBold | 层级清楚，不与主标题等重 |
| 正文、按钮 | 14 DIP；正文 Regular | 中文笔画清晰；按钮字重与真实字体匹配 |
| 辅助、元信息 | 12 DIP / Regular | 不继续缩小；用合格语义色而非整段降低透明度 |
| 数字 | 共享 Numeric 字体 | 计数变化稳定，数字与单位协调 |
| 路径、错误码 | 共享 Code 字体 | 完整查看/复制；混排中文不变方框 |

### 4.2 色彩与材质目标

主题按背景、侧栏、阅读表面、浮层、输入、选中、危险七种语义检查，不预先指定另一套色相。主操作和选中有明确强调；普通卡片边界安静，内容表面连续；深色避免一片黑或层层灰，浅色避免低对比灰字和发白的半透明按钮。

本项目采用：普通文字（包括 12/14 DIP 辅助文字）至少 4.5:1；只有符合大文本定义时才用 3:1。22 DIP SemiBold 标题不要自动按“大文本”豁免。禁用控件虽有标准例外，仍需可识别，禁用原因用正常可读文本呈现。依据 [W3C 文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

识别控件、焦点、选中与状态所必需的非文字视觉线索目标为相邻颜色至少 3:1；装饰性卡片细边不一律加深到 3:1，先判断边线是否承担必需辨识作用。依据 [W3C 非文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。这里是桌面产品采用的质量目标，不是宣称获得整项 WCAG 合规认证。

含透明度时按最终合成前景/背景计算，覆盖浅图、深图、高饱和复杂游戏背景；不能只测 token 的 RGB。文字裁剪边缘的抗锯齿像素不应直接当作字体设计色取样。报告记录资源值、合成层、测试背景和方法。

### 4.3 动效目标

以下是待 P04 校准的项目设计目标，不是外部平台的强制标准。

| 操作 | 时长入口 | 允许变化 | 完成与中断要求 |
| --- | --- | --- | --- |
| Hover / Focus | Fast 120ms | 局部覆层、轮廓、前景 | 焦点立即可辨，不等动画结束才反馈 |
| Press | Press 100ms | 现有模板实例缩放至 0.97 | 松开、失焦、卸载、变禁用后回到 1 |
| 导航、页签、详情 | Normal 220ms | 内容淡入、4～8 DIP 轻位移 | 操作立即提交；以最后意图收敛 |
| 少量较大浮层 | Slow 300ms 上限 | 淡入、轻位移 | 无焦点丢失或透明遮挡层残留 |
| 系统/用户关闭动画、高对比度 | 0ms | 直接应用终态 | 不保留位移、缩放或装饰等待 |

页面文字避免长时间缩放，滚动列表项不做入场波浪。不要让每个父子层同时淡入导致文字重复衰减。既有侧栏尺寸动画是受控例外，需单独测布局成本，不借此扩大 Width/Height 动画使用。

### 4.4 性能指标的测量定义

先记录 CPU/GPU、Windows/Playnite 版本、主题、分辨率、实际窗口与 PageHost DIP、DPI、显示刷新率、渲染 Tier、是否远程桌面、构建身份、数据规模。冷启动与热态分开；热态先预热 5 次，再至少测 30 次交互，滚动各测 3 段 30 秒。报告样本数、p50/p95/max、原始时间戳和可重复步骤。

| 指标 | 近期目标 | 计量边界 |
| --- | --- | --- |
| 输入到本地视觉反馈 | p95 ≤ 100ms | 从输入事件到反馈呈现，不含网络/Worker 业务完成 |
| 热态切页到内容可交互 | p95 ≤ 300ms | 已有数据页面；冷数据需立即显示真实加载态 |
| 60Hz 下稳定滚动/动画呈现帧间隔 | p95 ≤ 20ms，超过 33.3ms 的帧比例 ≤ 1% | 目标机热态；同时报告最长停顿；60Hz 一帧约 16.7ms |
| 明显 UI 线程阻塞 | 不出现可重复、由本插件引起的 > 100ms 停顿 | 用调用栈/trace 定位，外部宿主成本单列 |
| 快速操作恢复 | 20 次往返后布局、焦点、透明度和选择正确 | 不只判断动画 Completed 是否触发 |
| 长时资源 | 预热后 30 分钟不呈持续无界增长 | 内存、句柄、计时器、订阅、解码队列；缓存平台期可接受 |

上述是候选验收预算，尚未达成。目标机不足时报告实际值和瓶颈，不暗中放宽；非 60Hz 显示器按实际刷新间隔补充分析。`CompositionTarget.Rendering` 间隔仅是 WPF 回调代理指标，RenderHarness 计时仅是离屏指标；两者都不能单独证明屏幕实际呈现帧率。采用可用的呈现/ETW 分析工具，并用真实录屏定位卡顿时刻；录屏本身也可能丢帧，不单独作为精确延迟仪器。

### P01 — 中英文排版精修（4 项）

#### P01-01 字体回退与跨机器一致性

**实施提示词：** 在 Typography 唯一入口审计优选字体实际可用性、中文/英文/数字/标点命中及字重。比较优选字体存在和缺失两种环境，不通过卸载用户字体制造测试条件。优先保留现有回退链；若混排不可控，再评估同入口下 CompositeFont 语言/字区映射。不得按每个字符创建 Run 或自制排版引擎。

**验收/交付：** 提交字体决策表、两类环境样张和缺字检查。若随包嵌入字体，核对来源、具体文件许可、包体积、资源 URI 和 net462 加载；无可用字体资产时把分发作为明确待办，不能以本机装过字体宣称跨机一致。

#### P01-02 字阶、字重、行距与基线

**实施提示词：** 从 22/16/14/12 字阶起步逐类校准标题、正文、按钮、徽章和表头。检查中文笔画密度、Latin x-height、g/j/y 下伸部、中文括号与逗号的裁剪。用共享 Padding/VerticalContentAlignment 和必要的语义行距消除错位，避免负 Margin 或散布 BaselineOffset。

**验收/交付：** 同类控件的中文、英文和混排垂直节奏一致；正文两到三行自然，无上下裁字；100% 与 150% 下原尺寸截图可读，短窗表格仍满足四行底线。

#### P01-03 数字、单位与技术文本

**实施提示词：** 对统计卡、进度、大小、时间、路径和错误码应用 Numeric/Code 语义；对递增计数评估实际字体的等宽数字特性，并保留单位、空值和未知进度的真实区别。名称左对齐，数值列统一方向；长路径/错误保留完整查看和复制。格式化仅作用于显示，不改变排序键或复制载荷。

**验收/交付：** 9→10、99→100、9%→100%、KB→GB 时无整排抖动；中文路径和异常码完整可访问，空值不假装为 0；附变化序列对照。

#### P01-04 小字清晰度与文字透明度

**实施提示词：** 排查 TextBlock 及祖先 Opacity、OpacityMask、缓存、效果和变换。在 Caption 的 `GscMutedTextBrush + 0.65` 上先测最终合成，再用共享语义色表达层级，清理多层变淡。按实际表面比较 Ideal/Display、像素对齐和文本渲染模式；不能全局强制 ClearType 或 Display，也不把文字永久缩放到分数位置。

**验收/交付：** 原尺寸混排对照、辅助文字对比报告和 DPI 样本；文字静止后无残留缩放/模糊，禁用说明可读；具体渲染模式选择需有证据。

### P02 — 色彩、层次与材质（4 项）

#### P02-01 浅深主题层次校准

**实施提示词：** 读取 DesignTokens 与 AdaptiveThemePalette 的实际覆写，为背景、阅读面、浮层、输入和选中建立配对色板。修正浅色发白、深色层次黏连和局部色温漂移；保持 Demo 的色彩关系，不逐页手填新色值。

**验收/交付：** 浅/深/Follow 的同页对照与最终 token 表；主次信息明确，表格表头与正文连续，只有真实浮层有足够层次分离。

#### P02-02 对比度检查覆盖真实表面

**实施提示词：** 扩展现有 ContrastGuard 的语义检查，分别覆盖普通辅助文字、选中前景、按钮各态、输入 placeholder、错误和焦点。当前 SecondaryText 的 3.0 阈值不能用于普通小字；按第 4 节目标测最终合成色，不把装饰细边的 1.15 一律改成 3.0。

**验收/交付：** 列出每一语义配对、实际比值、阈值、是否装饰和例外原因；主要背景样本达标。保留正常文字与禁用例外的区别，不用“全都变黑/白”破坏层级。

#### P02-03 玻璃、轮廓和阴影收敛

**实施提示词：** 复核 Shell 唯一 ambient 层、阅读表面、玻璃按钮与弹层。保持页面 ambient 的现有透明策略；检查叠层导致的脏边、重复圆角、拼接缝和阴影被裁。优先低成本表面层次，保留已移除按钮顶部横线的结果，不恢复独立高光条。

**验收/交付：** 无整页重复矩形和侧栏/正文接缝；复杂背景上正文清楚；关闭玻璃仍有边界。提交阴影/叠层成本前后数据，不给列表行增加效果。

#### P02-04 强调色、状态色和主题热切换

**实施提示词：** 统一 Accent 在导航、主操作、焦点、选中上的职责，以及成功/警告/失败/进行中的语义色。覆盖 Popup、Tooltip、设置窗口和禁用状态的动态资源。切换主题时检查动画时钟是否还占着旧 Brush 值；避免对共享画刷实例直接动画。

**验收/交付：** Light→Dark→Follow 往返 20 次不出现旧色残留、闪白、选中文字不可见；红色不泛用于普通动作；状态始终有文字或图标辅助。

### P03 — 共享控件完成度（4 项）

**验收/交付：** 每类按钮状态联络图与键盘操作；按压不改布局、松开必回 1；禁用 Tooltip 可用。复合 Grid/Border 内容不被转成类型名；点击命令只执行一次。

#### P03-02 搜索框、输入与校验

**验收/交付：** 输入、光标、选择背景和 IME 组合文字不裁剪；placeholder 与真实值区别清楚；校验消息出现不挤掉保存入口，清除不误触其他命令。

#### P03-03 选择器、页签与开关

**实施提示词：** 在现有 ComboBox、Segmented/Tab、Toggle 模板上统一焦点、选中、Hover 和禁用表现；覆盖 Popup 边缘、选项行、箭头和长文本。保留当前游戏选框及 DropDownClosed 用户提交/程序同步的区分，不重新实现选择器。

**验收/交付：** 鼠标、方向键、Enter/Escape 切换正确，Popup 在边界内；可清楚区分选中与悬停；开关不显示与绑定相反的终态，切页不丢当前筛选。

#### P03-04 表格、图标与轻量分隔

**实施提示词：** 从共享 DataGrid、状态徽章和 ThemeAwareIcon 出发校准行内基线、图标视觉大小、排序箭头及列拖拽热区。沿用 52/42 DIP 行/表头起点和无独立底线的连续表头；保留行、选中、悬停间适度差异，不加逐行阴影。

**验收/交付：** 首末行、排序、列宽拖拽、横向滚动和多选均可用；图标缩放后笔画协调且不靠 emoji；媒体虚拟化例外原样通过，不以静态整表截图替代端点检查。

### P04 — 动效底座与生命周期（4 项）

#### P04-01 统一 XAML 与 C# 时长来源

**实施提示词：** 追踪 MotionTokens 与 GscMotion 全部调用，消除 Normal 220/200ms、Slow 300/320ms 双来源。保留既有入口，实现可验证的单一权威及无资源宿主的确定回退；不要只是再复制一份数字。时长按 Fast/Press/Normal/Slow 语义消费，继续 Cubic EaseOut。

**验收/交付：** 运行时测试验证模板和 C# 获取同一策略，无页面散落新毫秒值；缺字典、双主题和动画关闭可安全构造；输出调用点映射和最终值。

#### P04-02 连点打断与最后意图收敛

**实施提示词：** 审计导航、详情、侧栏和按钮的动画启动/取消/完成回调。新动画从当前可见状态接管，旧回调用代际或等价机制失效；状态先更新，动画只解释变化。不无限 Compose，不靠禁用全部 UI 阻止连点。

**验收/交付：** A→B→A、开→关→开、连续 20 次操作后与最后输入一致；没有反向跳帧、积累位移、幽灵浮层或错误隐藏新页面；提供行为测试与录屏。

#### P04-03 终态恢复与资源释放

**实施提示词：** 核查各控件实例的 Transform、Storyboard/AnimationClock、Completed、Rendering 和 Timer 订阅。在结束/取消/卸载时撤销旧时钟并正确建立终态，避免清除动画后回到错误基础值；重入和重新 Loaded 不重复挂订阅。

**验收/交付：** 100 次开合/切换后无活动时钟或订阅的无界增长；隐藏层不截获鼠标，透明度/缩放/位移、IsHitTestVisible 和焦点与真实状态一致。

#### P04-04 减动效与运行中设置切换

**实施提示词：** 统一用户动画设置、SystemParameters.ClientAreaAnimation 和高对比度判定，覆盖 XAML Trigger 与 C# 路径。在动画中途关闭动画/进入高对比度时，立即清理时钟并落最终状态；必要的任务状态提示继续显示。

**验收/交付：** 开/关动画和进入/退出高对比度矩阵正确；无“以后启动的动画才关闭”的遗漏，无透明半开面板；结束后恢复设置不会重播旧操作。

### P05 — 交互编排与连续反馈（4 项）

#### P05-01 导航与页签过渡

**实施提示词：** 以生产页面缓存和真实导航状态为基础，统一选中反馈、标题更新与内容淡入顺序；只对有限内容根做必要过渡，不让所有子项依次入场。切页保留筛选、滚动与选择，不为动画重建 VM 或重新查询。

**验收/交付：** 选中反馈及时，旧页不闪回，首次与再次进入行为合理；连续切页 30 次不多发请求、不丢页面状态，热态达到已确认的响应预算。

#### P05-02 Inspector、展开项和侧栏

**实施提示词：** 将详情开合、设置错误详情和侧栏收起作为有层级的状态变化统一处理。优先最终布局加轻量过渡；侧栏现有宽度动画例外先测成本再优化，不常规扩散布局动画。关闭后焦点回触发入口，详情内部滚动不影响主表锚点。

**验收/交付：** 开合过程中没有表格一帧挤成零高、错位点击或跳到顶端；短窗可触达详情尾部，连点和关闭动画终态正确；记录侧栏 Layout 次数和峰值间隔。

#### P05-03 加载、刷新与真实进度

**实施提示词：** 首载用已有状态 Presenter；刷新已有数据时保留可用内容与选择，清晰表示更新中/过期。局部 spinner 仅在真实操作期间运行，不让整页反复清空闪烁。确需延后加载提示以避免瞬闪时，只调整视觉提示并支持取消，绝不延迟命令或终态。

**验收/交付：** 快/慢/失败/取消/断连五类操作都不伪装成功；未知进度不显示 0% 或假进度，真实百分比不为追求平滑而落后终态；刷新不造成计数区抖动。

#### P05-04 Toast、Banner 与 Dialog

**实施提示词：** 复用当前反馈入口，统一进入、停留、退出和焦点规则。信息/成功提示不抢焦点；持续失败应有可找回的详情，不只瞬时 Toast。危险对话框保留对象、影响、确认和取消语义；减少重复通知但不丢失不同任务失败。

**验收/交付：** 多通知、长文本、鼠标悬停/键盘访问、Esc 和窗口缩放均正确；关闭后不留遮罩；取消不执行危险命令，确认不因动画回调执行两次。

### P06 — 操作响应与数据界面性能（4 项）

#### P06-01 UI 线程热点定位

**实施提示词：** 对首开、切页、筛选、刷新和主题切换采样，区分 Measure/Arrange、资源构造、Binding、集合通知、同步 I/O 和宿主成本。只优化已确认的表现层热点；禁止靠后台线程直接操作 WPF 对象，禁止用随处 Dispatcher.BeginInvoke 掩盖长任务。

**验收/交付：** 每项优化都有前后同条件时间和调用栈；无新 Binding 错误、线程异常、延后状态丢失。涉及业务服务瓶颈时列独立依赖，不在精修任务中重写 Worker。

#### P06-02 高频状态刷新合并

**实施提示词：** 审计任务进度、统计和筛选的 UI 通知频率，复用现有最新请求/代际与合并更新机制。可合并中间显示刷新，但成功、失败、取消和用户输入的最新结果立即可达；保留写请求安全语义，不改服务端进度或排序规则。

**验收/交付：** 模拟高频事件时列表不整页重建，选择保持；记录 Dispatcher/集合通知数量和反馈延迟；连续筛选最终只展示最新条件，关键终态零遗漏。

#### P06-03 缩略图和预览稳定性

**实施提示词：** 在 AsyncThumbnailImage/Loader 现有可见性、取消、代际、3 路并发和 96 项缓存基线上检查解码大小、占位与尺寸稳定。仅对当前可见图片必要地淡入；快速滚动中不对回收容器重复动画。错误占位保留真实重试/打开路径。

**验收/交付：** 缺图、损坏图、超大图、快速换游戏和滚动回收不串图、不闪旧图；活动解码与缓存有界，图片到达不改变行高；附内存和并发测量。

#### P06-04 大表滚动与分页锚点

**实施提示词：** 使用真实生产表格与隔离大数据夹具，对上下端点、鼠标滑块、滚轮、键盘、横向条显隐和加载更多采样。保留有限视口、内部滚动和现有系统；媒体的 Standard/Item/关闭列虚拟化等是已验证例外，不用统一模板运动方式“修顺滑”。

**验收/交付：** 无空白带、尾行遮挡、选中漂移或越界 offset；记录总量、实际加载量、容器数和帧数据。1000/5000/20000 行输入测试须尊重各页分页/缓存窗口，不绕过生产限制全量绑定。

**验收/交付：** 名称不挤掉版本/操作，加载与失败不导致面板跳动；不为改善预览自动下载或运行可执行文件；风险分类、自动启动和跟踪限制保持。

#### P07-07 维护中心

**实施提示词：** 精修 MaintenanceView 的健康、云端队列、目录、设备和隔离账本。风险优先、说明次之、技术数据可展开；统一全量/已加载摘要和表格数值。已上传与远端已校验必须在视觉及文字上保持区别。

**验收/交付：** 健康/离线/认证失败/恢复待处理均有明确下一步；长错误与多个表格可滚动到尾部；只读 check 不被改成上传，隔离恢复确认不弱化。

#### P07-08 设置页

**实施提示词：** 精修 GameSaveCenterSettingsView 分类导航、字段组、说明、校验摘要和底部动作。复用当前窗口/Owner 优先的主题资源与紧凑错误摘要；标题、控件、帮助文字按固定节奏排列，说明不靠整体透明度变灰。

**验收/交付：** 保存、未保存、失败状态清楚；定位首个错误可键盘到达；长路径/多错误/窄窗不挤掉操作；真实保存阻断、取消与回滚保持，独立设置窗口主题一致。

### P08 — DPI、窗口和视觉几何（4 项）

#### P08-01 分数 DPI 与文字像素

**实施提示词：** 在 100/125/150/175/200% 实际 DPI 下检查混排、1 DIP 边线、圆角、图标和按压终态。记录物理像素与 DIP，不把放大截图作为 DPI 测试。按局部几何调 UseLayoutRounding/SnapsToDevicePixels，避免全页 Viewbox。

**验收/交付：** 原尺寸截图无明显字体裁剪、线条断裂和抖动；动画结束文字恢复清晰；不能实际切换的 DPI 项明确待验收。

#### P08-02 常用窗口与紧凑布局

**实施提示词：** 以 1040×700 为常用回归点，并覆盖 980×640、1100×720、1280×720、1366×768、1600×1000、1920×1080 逻辑外层夹具。记录各页实际可用尺寸，优先压缩装饰和次级摘要，不缩小正文、隐藏功能或无限放大表格。

**验收/交付：** 页面无非预期横向滚动，表格内部横滚可用；常用高度主表至少四行，弹层/详情尾部可达；所有恢复到宽窗的布局状态正确。

#### P08-03 多屏迁移与窗口恢复

**实施提示词：** 在宿主支持的 DPI 模式下验证跨不同 DPI 显示器、最大化/还原和窗口尺寸往返。检查 Popup、Tooltip、焦点框和图片解码是否跟随正确尺寸；不要修改 Playnite 的全局 DPI manifest 或 WindowChrome 来绕过宿主限制。

**验收/交付：** 迁移后菜单不漂到旧位置，文字不持续发虚，窗口恢复不丢页签/选择；记录宿主不支持的能力和可复现限制。

#### P08-04 边缘、遮挡与命中区域

**实施提示词：** 检查圆角内裁剪、弹层阴影、滚动条与最后一行、错误横幅和固定 footer 的交界。装饰层应不截获输入；可交互控件的实际 hit test 范围需与可见位置一致。尽量保留现有 36 DIP 常规操作命中区，紧凑例外单独登记。

**验收/交付：** 边角、最底端和横向两端可点击；Tooltip/菜单不被父面板裁断，透明层不吃点击；不以增大不可见遮挡区域制造“更好点”。

### P09 — 全状态、文案和可访问性（4 项）

#### P09-01 完整业务状态外观

**实施提示词：** 为六页和设置建立适用状态矩阵：首载、刷新、空数据、筛选无结果、离线、过期、失败、部分完成、取消、权限受限。复用 WorkspaceStatePresenter 和真实状态字段；一次优先呈现一个解释清晰的主要状态，避免重复错误墙。

**验收/交付：** 每种适用状态有对应真实 Binding/命令与夹具证据；不存在字段的场景登记不适用，不造假状态；失败和无结果提供合适下一步。

#### P09-02 中文文案与混排一致性

**实施提示词：** 建立简短术语表，统一备份/存档、扫描/校验、上传/远端校验、待归类/已忽略、重试/刷新。按钮用明确动词，单位/空格/日期按项目约定一致。保留用户游戏原名、路径、错误码和可复制原始诊断，不做字符串破坏性替换。

**验收/交付：** 同义入口不出现互相矛盾的叫法；首屏无类型全名和多余技术噪声；长英文/中文双倍长度夹具可用，完整诊断未被文案精简丢失。

#### P09-03 键盘与屏幕阅读器

**实施提示词：** 按导航→筛选→主表→详情→页尾顺序验证 Tab/Shift+Tab、方向键、Enter/Space/Esc 和既有快捷键。复核 AutomationProperties.Name/HelpText、焦点可见性和弹层焦点返回。错误定位和进度状态给必要通知，避免逐百分比播报。

**验收/交付：** 仅键盘可完成浏览、筛选、查看详情与取消；图标按钮有清晰名称，主表保留原生自动化语义；不能用反射 OnClick 测试冒充真实键盘或读屏验证。

#### P09-04 无透明、高对比与低动效组合

**实施提示词：** 验证显式浅深/Follow 与玻璃关闭、动画关闭、高对比度的组合，重点检查浮层、禁用控件、图标、选中和焦点。使用语义资源安全回退，所有入口仍可辨识；不靠保留大面积透明效果维持设计。

**验收/交付：** 组合切换无不可见文本、消失焦点或旧主题 Popup；状态不用颜色单独表达；报告哪些是运行时验证、哪些仅有源码断言。

### P10 — 性能、耐久与真实体验（4 项）

#### P10-01 帧时间和响应预算验收

**实施提示词：** 在同目标机按第 4.4 节重跑输入、导航、详情和表格滚动，采集呈现/线程证据并与 P00 对照。报告 p50/p95/max、慢帧比例、冷/热和样本数，不以平均值隐藏卡顿。预算未达成则定位最高影响热点继续修复。

**验收/交付：** 原始样本、对照表和至少一个真实卡顿时刻的归因或无重复卡顿证据；无法获取实际呈现数据时标为代理测量，不能签署帧率达标。

#### P10-02 连续使用与生命周期耐久

**实施提示词：** 在隔离数据下连续 30 分钟执行导航、筛选、详情开合、预览和主题切换，区分预热缓存增长与泄漏。检查活动动画、Timer、Rendering/事件订阅、图片解码和 UI 对象存活；不要依靠生产强制 GC 或定时重建页面抑制增长。

**验收/交付：** 时间序列显示资源进入合理平台期，关闭页面/窗口后按生命周期释放；每条新增泄漏修复有根因与针对性回归，未测足 30 分钟不能写耐久通过。

#### P10-03 低性能与高负载降级

**实施提示词：** 覆盖低渲染 Tier/可用的低性能测试环境、复杂游戏背景和后台任务高频刷新。先限制阴影、环境层与非必要动画，再评估既有关闭玻璃/动画设置的回退效果；不要关闭虚拟化、吞掉任务事件或自行改宿主渲染策略。

**验收/交付：** 降级仍可读、可操作、终态正确；报告目标机和降级策略，不将高性能机器结果外推到全部设备；数据查询慢与视觉慢分开呈现。

#### P10-04 真实路径体验走查

**实施提示词：** 在获授权的宿主/隔离数据中走查：打开→选游戏→存档详情→任务详情→媒体筛选/预览→维护只读明细→设置查看。每条记录读懂主操作、找到错误下一步、滚动到尾部和返回原位置的过程；危险动作只验证取消，写操作另按既有授权与隔离夹具执行。

**验收/交付：** 每条路径有步骤、可见证据、时刻与缺陷；全部使用真实生产控件。原始录屏可能含私有路径，公开或纳入 Git 的证据使用脱敏/合成数据。

### P11 — 最终修正与交付（4 项）

#### P11-01 跨页面视觉一致性评审

**实施提示词：** 将八个页面/壳层入口在同主题、同 DPI、同尺寸并排检查，按字体/层级、颜色/材质、控件、动效、响应、窗口适配、可访问性、业务状态八维评分。每维 1～5 分：3 为基本可用，4 为稳定一致，5 为经细节和异常路径复核的成熟效果；低分必须链接具体缺陷。

**验收/交付：** 目标各维至少 4 分，并且没有裁剪、不可读、命令错误、焦点丢失和可重复卡顿等阻断项。评分只辅助评审，不能覆盖性能不达标或宿主未验收。

#### P11-02 回归与跳过账本

**实施提示词：** 运行当前构建、测试、源码/XAML、WPF 静态检查和完整 RenderHarness；按影响范围检查真实宿主矩阵。只补有意义的行为/资源解析/动画中断测试，避免写大量与实现逐字相同的断言。失败定位后修复，skip 逐项说明原因和剩余风险。

**验收/交付：** 零未解释失败、新增 Binding/XAML 错误为零；每种证据来源明确，日志和执行退出码可追溯。历史测试数量不作为新一轮通过数量抄写。

#### P11-03 包身份与宿主加载验收

**实施提示词：** 对最终已提交生产源生成候选包，核对版本、Git 构建身份、包内程序集和实际安装 DLL。按现有安装授权与脚本安全检查完成安装/重启，确认日志加载，并打开真实生产页面核查关键视觉变化。已有用户文件不纳入源码快照。

**验收/交付：** 包、安装目录、运行日志身份一致；源码 HEAD 与包构建 HEAD 分别记录。没有真实打开页面只能签“安装/加载通过”，不能签“最终视觉通过”；禁止把旧包截图作新代码效果。

#### P11-04 文档、证据与最终签收

**实施提示词：** 更新 CURRENT_STATE、PROJECT_MEMORY、WORKLOG、DEVELOPMENT_HANDOFF 和本计划状态。整理最终资源表、字号/色彩/动效决策、前后对照、性能原始数据及待宿主项。核对 artifacts/.tmp 内本阶段临时目录，只清理已经不需要的产物；保留最新包和当前引用证据。

**验收/交付：** 提交并推送中文 commit，列出准确 Git 状态与下一步；只有视觉、交互、性能、真实宿主四类证据齐全才写“本计划最终通过”。否则写已完成范围与具体剩余项，交接可继续执行。

## 6. 工程验证与实施边界

代码阶段的常用命令如下；从仓库根执行，先确认本机参数和环境。本提示词文档创建本身不触发安装/运行宿主，也不改应用版本。

```powershell
git status --short --branch
git log -20 --oneline
python scripts/validate-source.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-xaml.ps1
python .codex/skills/wpf-apple-desktop-ui/scripts/validate_wpf_ui.py .
.\scripts\build.cmd -Configuration Release -OutputRoot .tmp/ui-finesse-build-current
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render-qa.ps1 -Configuration Release -Output .tmp/ui-finesse-qa-current
git diff --check
```

不要并行执行会竞争同一 bin/obj、包 staging 或宿主的构建/安装流程。既有输出正在使用时选择新的阶段目录，验证后清理旧目录；递归删除前确认绝对路径在仓库 `.tmp/` 或 `artifacts/` 内，用 PowerShell `Remove-Item -LiteralPath -Recurse -Force`，不跨 shell。

项目记忆还要求交付前一键构建安装运行及真实宿主验证；该链会影响 Playnite 扩展目录和进程，执行前读取脚本并核实当前会话已有授权与目标环境。安全门禁不通过时保留阻塞说明，先完成不依赖宿主的工作，不能把 `build.cmd` 写成安装门禁已通过，也不能通过修改用户主题/全局设置绕过。

纯色彩/间距微调不必新增镜像实现的单元测试，但仍需受影响控件各态/双主题的可见检查。字体回退、资源合并、焦点、动画中断、异步回写和集合性能变化需要对应行为测试。共享修改覆盖所有消费页面，不能仅验首页。

## 8. 技术依据与适用方式

以下于 2026-09-13 核对官方资料，仅支撑具体机制；本文视觉数值、时长与性能预算是项目目标，并非照搬某一平台规范。

- [Microsoft：Typography in WPF](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/typography-in-wpf)：WPF 支持 OpenType 和 CompositeFont 多语言映射。用于 P01 的字体回退方案评估；具体字形/字重仍需 net462 和目标机验证。

- [Microsoft：Optimizing Performance — Text](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-text)：文字排版与额外文本结构存在成本。用于 P01/P06 保持普通生产控件轻量，不要求把 TextBlock 换成低层 GlyphRun。
- [Microsoft：Taking Advantage of Hardware](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-taking-advantage-of-hardware)：渲染像素量与硬件能力影响 WPF 成本。用于 P02/P10 控制大面积效果并记录测试环境，不等同保证 GPU 动画一定不卡。
- 对比度规则见第 4.2 节就近链接；工程事实以当前源码、[CURRENT_STATE](../ai/CURRENT_STATE.md)、[UI_CHANGE_GATE](UI_CHANGE_GATE.md) 和 [项目技能](../../.codex/skills/wpf-apple-desktop-ui/SKILL.md) 为依据。
