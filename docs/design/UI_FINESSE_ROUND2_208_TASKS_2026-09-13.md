## 3. 证据与质量门禁

### 3.1 分维度记账

- 自动验证、视觉：待验 / 通过 / 失败 / 不适用，均链接实际证据。
- 宿主：待验 / 通过 / 外部阻塞 / 不适用，说明为何不适用。
- 最终结论：未完成 / 已验收 / 已满足 / 不适用；前三列存在缺口不能以“已存在”直接签收。
- 受控 WPF 行为可证明绑定、终态或几何，不证明物理输入和屏幕呈现；真实宿主 unavailable 不影响继续补受控测试。

代码 SHA、夹具 SHA、数据种子、主题、窗体物理尺寸、PageHost DIP、DPI、字体环境、CaptureOrigin、测量方法和时间必须随证据记录。候选包和安装包 SHA 独立记录，不把最后一次文档提交当生产程序集来源。

### 3.2 共用验收卡

每个控件至少核对适用的 Normal、Hover、Pressed、Keyboard Focus、Disabled、Selected/Checked、Error/Busy，以及 Focus+Hover、Selected+Hover、Pressed→Disabled 等组合。默认检查 Light/Dark，受主题影响的修改加 Follow/高对比/无透明；动画修改加关闭动画和运行中关闭。共享模板修改必须抽查所有消费类型，不能只验一个校对页。

普通 12/14 DIP 文字目标 4.5:1；用于 11 DIP 诊断的状态色同样按普通文字检查，并优先纠正必要文字过小。图形与装饰有不同责任，不把所有边框加深。透明/渐变按最终合成与最差位置检查；先用未舍入数值比较，再格式化显示。[W3C 文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

默认在 1040×700、1366×768、1600×1000 的外层夹具做双主题对照，记录真正 PageHost；涉及响应式再扩展旧计划矩阵。实际 DPI 覆盖 100/125/150/175/200%，不能用软件放大 PNG 代替。

动画仍消费共享 120/100/220/300ms 语义，数值不是“必须每个控件都动画”的要求。焦点与主反馈及时出现，允许最后意图打断，离开页面释放时钟与订阅；不延迟业务命令来等动画，不对虚拟行新增连续动效。

性能沿用旧计划：热态输入反馈 p95≤100ms、热态切页可交互 p95≤300ms；60Hz 实际呈现帧间隔 p95≤20ms、>33.3ms 比例≤1%，报告最大停顿。均为项目目标而非已达事实。至少预热5次、测30次；滚动3段各30秒；冷启动、远程桌面、低 Tier 分开记录。实际呈现不可测时明确缺证，不拿代理替代。

### 3.3 交付顺序与检查命令

先跑有意义的相关资源/行为测试与图像检查；每个独立阶段按仓库门禁做 Release 构建测试、源码/XAML/WPF 和适用 RenderHarness。同一次共享模板修复可覆盖多行，禁止重复几十次相同全量检查冒充工作。

git log -20 --oneline

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-xaml.ps1

实际使用前核对当前脚本参数；输出路径按阶段避免与在用进程冲突。一键安装链与 package/真实宿主审计先读脚本并确认副作用及授权；本次父任务只审计与交付文档，不宣称完成新安装。不要并行构建到同一 bin/obj/staging。

仅文案/间距微调不必写镜像实现测试；资源解析、事件次数、焦点、动画中断、异步生命周期需要行为回归。自动通过后必须查看截图；发现明显黑字、裁剪或缺状态时修复夹具判定，不能把报告继续标无问题。
