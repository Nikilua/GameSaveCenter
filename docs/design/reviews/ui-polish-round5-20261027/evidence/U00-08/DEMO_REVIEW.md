# U00-08 — 存档示范页整体验收复核

日期：2026-10-27。目标为生产 `SaveCenterView`；本轮不迁移共享模板，也不将受控离屏结果称作真实 Playnite/Demo 验收。

## 组合后的双主题复核

| 方面 | Light / Dark 观察 | 决定 |
| --- | --- | --- |
| 字体与层级 | 页面标题、摘要标签/数值、正文和辅助信息沿用生产 Typography / DesignTokens 资源；摘要卡内的上下文胶囊与辅助说明仍能区分。 | 延续U00-03标题/操作层级和U00-04 8/12 DIP间距；没有新建第二套字体令牌。 |
| 颜色与状态 | Ready、Empty、Loading、Error、Stale、Offline状态均有文本/状态提示；浅深主题采用既有动态资源。 Stale仍显示旧列表与过期说明。 | 保留状态文案和真实恢复/重试语义；不以颜色替代文字。 |
| 控件与内容 | Ready与多选长文本样本中保留筛选、摘要、动作、表格及详情路径；文本按列省略时可以从ToolTip读取完整样本文案。 | 保留现有真实命令、Binding、游戏选框、列和滚动条；夹具没有调用破坏性命令。 |
| 1040 DIP节奏 | Light/Dark 在1040×700下没有因摘要间距改动新增换行或挤压；现存紧凑操作组换行仍存在，主表保留4条可读行。 | 间距改动只作用于生产存档页摘要区，暂不推广到共享模板。 |
| 更宽/高分辨率 | 双主题Ready/多选样本覆盖1366×768；状态报告另覆盖1100×720与2560×1440逻辑DIP。 | 这些离屏逻辑尺寸结果不推导物理DPI或所有宿主布局通过。 |

截图、像素哈希、完整56张状态矩阵报告见[U00-04/05样张](../U00-04-05/BASELINE.md)及其 `screenshots.json`；报告证明的核心矩阵为浅/深主题×4个逻辑窗口尺寸×7类存档状态。U00-01的逐页差异和截图路径见[基线观察](../U00-01/BASELINE.md)。本复核复用既有样张，不复制同SHA图像。

## Demo-first与推广判断

仓库当前没有 `GameSaveCenter.AcrylicFork/.../Design/DesignShellView.xaml`、`Design/Pages` 或 `GameSaveCenter.WpfUiDemo.v3.1` 源。按项目规则不伪造对照，不声称存档页已经与Demo一致；本批只证明生产页面双主题和隔离状态在样本范围内保持清晰。U00-04/05尚无共享ControlTemplate改动，因此还没有可推广到共享体系的本批资源差异。Demo源恢复可用后，需先对照其页面结构、层级、色彩及控件，再做共享迁移。

## 未验范围

- 真实Playnite宿主外壳与宿主当前游戏选框、UI Automation树、真实键盘/IME和用户物理输入未在这些截图中验证。
- DPI均为受控逻辑DPI 1.00；没有声称125%至200%物理缩放或用户另一台电脑通过。
- 设置页基线样本仍处于校验错误状态；有效默认配置截图需要单独的隔离设置夹具。
- 真实存档恢复、媒体删除与云端写入没有触发。
- 中文包装器完整构建/测试/发布/安装身份/启动链、独立`scripts/build.cmd`职责验证和GitHub新提交的SDK8/SDK10结论仍待各自证据；本页复核不替代这些门禁。
