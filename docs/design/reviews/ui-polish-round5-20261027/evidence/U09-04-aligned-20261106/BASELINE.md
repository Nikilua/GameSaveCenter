# U09-04 同条件性能复测：U00 与 a13a7dbb

本阶段在 SDK 8.0.423 下，对 U00 源码 `5d0a2448d6315af61571d0d3fbecfd902e5344fc` 与当前冻结候选 `a13a7dbbe27f4cb90d37057163e1481aa8abf355` 做了两组顺序相反的受控 WPF 配对。每次均使用 1040×700 DIP、双主题、七个假工作区、固定样本 UTC `2026-10-27T00:00:00Z`、60 秒活动和 30 秒稳定观察。窗口始终隐藏、置于屏幕外且 Opacity=0.01。没有把窗口带到用户桌面，没有修改盘符或映射。

U00 与候选复用同一版 a13 RenderHarness `Program.cs`、`FakeDashboardData.cs` 和 `FakeSampleClock.cs`。由于 U00 的 `NotificationRecordDto` 没有 `Source` 属性，只在临时 U00 假数据文件中移除了三个不兼容的初始化字段。两侧 Harness 程序源码 SHA 均为 `59DE608B4F30B518B6D877F05663EF0A4056A829178D3BD45BFD3F5A25A67627`。后续归属探针在两侧使用字节相同的临时测量代码；计时器停止后才追加预分配的值元组，并在 `allocatedAtRunEnd` 后格式化文本。所有修改都只在 `.tmp/` 快照中，没有进入生产源码或提交。

## 配对结果

| 动作代理 | U00 → 候选，正序 | U00 → 候选，反序 | 解读 |
| --- | ---: | ---: | --- |
| 全工作区动作周期 P95 | 731.13 → 862.94 ms | 889.21 → 888.74 ms | 两轮方向不同，整页 P95 受 Dispatcher/桌面调度长尾影响，不能判为稳定回退。 |
| 最大可滚动器 `scroll_offset` P95 | 17.65 → 31.60 ms | 16.61 → 29.42 ms | 候选在该整页滚动代理上的两轮样本均较慢，仍不是物理输入或呈现帧。 |
| 详情收起 P95 | 10.85 → 18.99 ms | 10.67 → 19.68 ms | 候选逻辑布局代理增加约 8–9 ms；需宿主复核。 |
| 详情打开 P95 | 37.13 → 40.13 ms | 37.00 → 36.84 ms | 两轮接近。 |
| 工作区切换布局 P95 | 711.45 → 766.91 ms | 711.17 → 791.78 ms | 候选中位数较低，尾部仍有分散的单次高值；不据此声称页面切换帧卡顿。 |
| 活动段托管累计分配 | 13,175,764,656 → 11,415,327,064 bytes | 13,175,959,496 → 11,509,964,064 bytes | 候选总分配低约 13.36% / 12.64%，尽管完成动作更多。 |

更细的页面归属采样把较慢的滚动样本定位到 Task 页，但未记录具体滚动器身份：其每主题约 5–7 个样本，候选中位数约 27–29 ms，U00 约 14–16 ms。一次 U00 深色样本为 690.84 ms。详情收起通常约 7 ms 对 18–19 ms，但候选单次出现 677.48 ms 尖峰。小样本和反向顺序的全局周期 P95 变化说明桌面/Dispatcher 噪声显著。现有 TaskGrid 内部 `DG_ScrollViewer` 专项没有同样回退：Light P95 16.526→16.409 ms，Dark 16.498→16.499 ms，详见[TaskGrid 归属复测](../U09-04-taskgrid-scroll-20261102/BASELINE.md)。

因此，当前能确认的是**Task 页所选滚动器与详情收起的受控布局代理较慢**，TaskGrid 内部滚动代理基本持平，累计托管分配下降；目前没有足够稳定的测量把差异归因到单一控件或源代码改动。源码复核：探针先触发详情收起和同步布局，再从当前可见滚动器中按 ScrollableHeight 取最大值，未记录 Name、模板宿主、视口或实际位移。TaskPageScrollViewer 明确使用 DIP，TaskGrid 允许内容逻辑滚动，两者的 ScrollableHeight 不能直接按同一物理距离比较。专项结果只证明 TaskGrid 在独立固定场景下持平，无法排除其参与综合探针。下次同条件测量应分别绑定页面、详情和表格滚动器，固定布局与详情状态，并记录目标和实际偏移后再比较。没有延长动画来掩盖差异，也没有为离屏单次长尾贸然更改生产实现。

## 动效与验证边界

双主题动效结构探针在同源下能完成进入、中断反转、卸载复位。固定时钟 U00 单次切换的 `CompositionTarget.Rendering` 回调间隔代理 P95/最大为 33.6/39.2 ms。另有一份候选较早成功报告为 31.4/42.5 ms，但该份样本时间未固定，不用于同条件比较。固定时间候选首次深色中点样本失败（210 ms 时仍为宽度 270、透明度 0），精确重试通过；重试出现一次 681.6 ms 单回调间隔，快速反转探针则为 34.5/36.7 ms。该失败及两张深色中点对照图均保留。结果显示离屏 Dispatcher 回调存在显著调度噪声；回调间隔不是 DWM/合成器实际呈现帧，也不证明用户看到掉帧。

这些测量都来自受控离屏 WPF STA 窗口。没有采集 Playnite 前台窗口 ETW/DWM 实际呈现时序，没有物理滚轮/键盘/IME输入时延、外部 UIA 或实际 DPI 数据；因此 U09-04 仍待真实宿主性能验收。未执行真实存档恢复、媒体删除或云端写入。本阶段没有生产 UI 源码变更；最终候选的 UI_CHANGE_GATE、本机完整构建安装启动链和 SDK8/SDK10 源码 CI 已分别由 `a13a7dbb` 与其既有证据覆盖。
