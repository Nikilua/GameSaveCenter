# 用户截图反馈：页面滚动视口边界复修

## 问题与修复

用户截图显示存档历史表格的滚动条延伸进入下方详情区，任务队列表格滚动条在可见区域下方仍继续，路径候选的行和详情被裁切。此前 `43b869d1` 已把紧凑工具区与详情入口移出表格框架；再次检查发现，当页面 `ScrollViewer.ViewportHeight` 已经有效时，`ResolvePageViewportHeight` 仍可能优先采用包含页面标签和其他 chrome 的宿主高度，导致表格预算越过页面实际滚动视口。

`a1a86e41` 修正高度来源：宿主和实测页面视口都有效时取较小值；页面视口尚未测出时才使用宿主值。该上限同时作用于存档历史/候选路径与任务表格的页面空间预算。剩余空间不足以容纳详情时，详情保持在外层页面滚动内容中，不再允许表格内部滚动越界。
