## 发现的问题

WPF `BeginAnimation` 默认会保留完成态时钟。此前部分 Dashboard 入口没有显式生命周期策略：对话框关闭只清除透明度动画，没有清除位移；`ClearToasts()` 直接清空 Children，绕过了逐卡的动画和 DispatcherTimer 清理；通用位移、入场、状态胶囊和页面切换路径的完成态也没有统一收口。

## 当前实现

- `GscMotion.AnimateTranslate` 与 `AnimateEntrance` 在替换旧动画前捕获当前有效值，使用显式 `FillBehavior.HoldEnd` 保持到完成回调，再移除 X/Y/Opacity 时钟并写回最终值；重入不会回到旧起点。
- Dashboard 的页面/状态/缩放动效、对话框和 Toast 入场都在完成回调中清时钟并写回终态。对话框用 `dialogMotionGeneration` 使旧的异步完成回调在关闭或重新打开后失效，`StopDialogMotion()` 同时清理透明度和 Y 位移。
- Dashboard 卸载时先失效对话框动画代际，再归一化主壳、可见 PageHost、工作区面板、状态胶囊和任务详情卡；Toast 先复制当前卡片并逐一调用 `RemoveToast()`，由该入口停止 Timer、清除 Opacity/X 动画，最后才清空容器。
- AcrylicProductionShellView 的侧栏宽度、透明度和位移动效显式声明完成态策略；完成和 reduced-motion 路径清理对应时钟并写回目标宽度/位置，Unloaded 路径清理时钟并归一化透明度/位移。
- `UiFinesseFoundationTests.MotionAnimationsReleaseClocksAtTheirFinalValues` 在真实 STA WPF `Window`/PresentationSource 宿主中运行 `AnimateTranslate` 与 `AnimateEntrance`；动画完成后断言 X/Y/Opacity 均为终值，且 `DependencyPropertyHelper` 报告不再处于动画状态。
- `ProductionShellChromeSourceTests.SidebarTransitionReleasesClocksOnCompletionAndUnloadInAnActualWpfWindow` 在真实 STA WPF `Window` 中触发生产侧栏按钮：完成态断言 Width/Opacity/X 无活动时钟；随后在长动画中关闭窗口并推进 Dispatcher，断言 Unloaded 清理结束过渡、释放 Opacity/X 时钟并将位移归零。该回归促成 `AcrylicProductionShellView.OnUnloaded` 写回 `TranslateTransform.X = 0`。
