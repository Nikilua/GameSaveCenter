# Q18-01 动效资源的真实宿主解析路径

采集日期：2026-09-15（Asia/Shanghai）。当前代码基线：`8dfe7fa`。

## 修复前的假阳性

已有 `MotionHostResourceOverridesTheCanonicalTokenWithoutChangingFallbacks` 只证明 `GscMotion.GetDuration(host, ...)` 本身能读取局部资源；生产入口却把 `GscMotion.Fast/Normal` 静态属性直接传给动画，局部 `GscMotion*` 覆盖因此无法到达真实调用路径。

## 当前实现

- `GscMotion.AnimateTranslate` 新增 `MotionDurationKind` 重载，并从传入的 `FrameworkElement` 解析时长。
- `AnimateEntrance` 的 Normal/Slow 时长从自身元素解析；Dashboard 的状态胶囊、对话框和 Toast 分别从对应视觉宿主解析；壳层侧栏的宽度、淡入和位移共享 `SidebarContentLayer` 的解析结果；Overview/Dashboard 的 Hover 入口也传入时长类型而非静态时长。
- 当前生产 UI 源码中 `GscMotion.Fast/Normal/Slow/Press` 仅保留在基础设施的兼容属性和测试中，入口不再绕过资源宿主。

## 验证

- 定向 Playnite 测试：`202/202` 通过范围内无失败，39 项既有宿主布局测试按项目边界跳过。
- Release 全量：Core `83/83`，Worker `310/311`（1 skip），Playnite `485/548`（63 skip），失败 `0`。
- `python scripts/validate-source.py` 和 `scripts/check-xaml.ps1` 均通过。

该证据证明资源覆盖已经进入生产调用路径，但不替代真实宿主热切换、系统动画偏好变化和物理屏幕帧验收；Q18-01 的视觉/宿主列仍按台账保持边界。
