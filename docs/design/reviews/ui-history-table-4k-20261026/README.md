# 存档历史表格高分辨率伸缩回归

## 用户现象与根因

用户报告：在另一台 4K 电脑上，存档中心“历史版本”页的表格随窗口拉伸仍保持原尺寸，周围出现空白。复核现有 `UI-SCROLL-LAYOUT-REPAIR-20261020` 视口预算后发现，`SaveHistoryGrid` 的剩余高度仍被 `560 DIP` 常量截断；同一 RenderHarness 的旧记录在 `2560×1440` 下测到的视口正是 `560 DIP`。

## 修复范围

- 历史表格按当前 PageHost 高度扣除摘要/框架/详情后得到的 `historyTableBudget` 分配视口，不再套用桌面尺寸上限；表格自身的滚动、Recycle 虚拟化及外层页面滚动继续保留。
- 增加从 `900×900` 收缩至 `900×600`，再扩展到 `3840×2160` 逻辑 DIP 的 WPF 回归，确认历史表格随高窗增大、缩回后变小，所选版本详情仍可达。
- 复用既有滚动预算逻辑；这项是 `UI-SCROLL-LAYOUT-REPAIR-20261020` 留下的固定上限后续，不重复改共享滚动条、游戏选框、命令/绑定或业务安全语义。候选路径页不在本次报告范围。
