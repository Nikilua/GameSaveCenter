# UI3-00/01 媒体收件箱证据

本目录保留同一离屏夹具（1040×700，媒体中心「待归类」页）的改造前后截图：

- [改造前](Media-1040x700-before.png)：右侧详情面板挤压列表，批量操作换行，首屏无法读到媒体行。
- [改造后](Media-1040x700-after.png)：批量主操作保持单行，表格使用有限且可虚拟化的视口，首屏可读 4 行；详情面板在窄宽度下由按钮打开，次级动作移至页内滚动区。

验证命令：`scripts/render-qa.ps1 -Configuration Release -Output .tmp/ui3-final-latest`

生产壳层夹具在 1040×700、1100×720、1366×768 下的 PageHost 分别为 715×577、775×597、1041×645；媒体页滚动通道均为可用，表格高度分别为 357、377、420 DIP。该夹具是离屏布局验证，不等同于实际 Playnite 宿主渲染。
