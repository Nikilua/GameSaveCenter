# R03-08 用户文本缩放证据（2026-09-17）

## 结论

R03-08 的当前生产可控范围已满足表格条件：默认字号和较大文本资源覆盖下，输入框、文本按钮和 DataGrid 表头不再依赖固定高度裁切；较大文本通过自然增长和表头换行保留可见内容。代码提交为 `981b600f20a2dc3ce57eb9f3cd70c4d6c1d4d970`（`支持较大文本下控件自然增长`），已推送到 `codex/ui-finesse-round2`。

- 先核对现有资源和控件链：`GscBodyFontSize`、`GscCaptionFontSize`、`GscButtonHeight`、`GscTableHeaderHeight` 仍是共享 DynamicResource；没有新增字体体系，也没有用缩小字号适配。
- 共享 `GscWpfUiTextBox`、远程恢复/媒体批处理按钮和只读完整路径框移除硬 `Height`，保留 `MinHeight`、现有模板、内边距、只读/复制语义和命令状态。Overview 两个保护动作也移除页面级硬高，保留 `MinHeight` 与原有 Command/Tooltip/安全提示。
- 共享 DataGrid 不再设置 `ColumnHeaderHeight`；`DataGridColumnHeader` 保留 `GscTableHeaderHeight` 最小节奏，并通过 `GscDataGridHeaderTextTemplate` 使用 `TextWrapping=Wrap`、`TextTrimming=None`。Task、Media、Dashboard、Redesign 和开发探针中的重复表头硬高覆盖同步移除。
- `R03TextScaleTests` 定向 `2/2`：将生产窗口资源中的正文/说明字号覆盖到 `24/20 DIP`，实际 STA WPF 同时测量可换行输入框、媒体批处理按钮和 DataGrid 表头；断言控件按自然需求增长、内容宿主不小于需求、表头不小于共享最小高度，且按钮模板不省略文本。源码负例还确认相关生产样式区段没有重新引入硬高。
- 受影响的既有断言已按原责任校正：共享输入/动作测试继续检查 `MinHeight`、居中和内容宿主可见性；搜索框测试允许自然增长但仍检查纵向不裁切；合法的图标按钮 `34 DIP` 固定尺寸未被误报。
- 隔离 Release 全量：XAML `24/24`；构建 `0` 警告、`0` 错误；Core `83/83`、Worker `311/311`、Playnite `568/625` 通过、`57` 跳过、`0` 失败；`validate-source.py` 与 `git diff --check` 通过。
- clean commit 上的双主题 RenderHarness 绑定 `981b600`，`WorkingTreeClean=True`，`render-qa OK`，共 `357` 张 PNG；1040/1100/1366/2560 DIP 页面、滚动/虚拟化、Shell/resize 均通过，人工抽查 Light/Dark Task、Light Media 和 Dark Save 代表图。

## 受影响控件与安全边界

| 范围 | 调整 | 保留的契约 |
| --- | --- | --- |
| 文本输入 | 去掉硬 `Height`，保留共享 `MinHeight` 与生产 TextBox 模板 | 选择、编辑、绑定、焦点、隐藏水平滚动条和错误语义不变 |
| 文本按钮 | 去掉页面/派生样式硬 `Height`，保留宽度、最小高度和共享按钮状态 | Command、Binding、禁用/忙碌状态、焦点环和安全 Tooltip 不变 |
| 表头 | 去掉 `ColumnHeaderHeight` 覆盖，保留 `MinHeight`，正文允许换行 | DataGrid 行高、现有滚动条和有限列表策略不变 |
| 完整路径框 | 去掉固定 `34 DIP` 高，保留 `MinHeight=34` 与只读路径展示 | 路径原值、选择和 R03-05 复制命令不变 |

本轮没有修改游戏选框、滚动条系统、命令/Binding、取消/错误语义、恢复保护、有限列表性能或 Playnite/net462 目标；只使用合成文本、隔离 Window 和隔离构建输出，没有写真实存档、媒体、云端或 OS 剪贴板。
