日期：2026-09-22

## 本子批次结论

`FilterConditionSummary.StaleStateDetail` 原先在用户可见的云端队列 stale banner 中直接拼接本地时间。本批复用 `TimeDisplayFormatter`，让“上次成功读取”同时显示相对时间与完整本地/UTC 投影；没有成功读取时间时不虚构时间，只保留真实刷新失败原因。

- `StaleStateDetail` 增加可注入 `nowUtc`，生产调用继续使用当前 UTC，测试可固定参考时间。
- 云端队列的旧数据保留、刷新命令、失败原因、筛选、分页、命令绑定、取消/错误语义均未改变。
- `RecentAccessItem.LastAccessDisplay` 保持兼容属性不改；Overview 实际用户文本仍使用既有相对时间，完整时间仍在 Tooltip/Automation HelpText。本批没有把未使用兼容属性当成新的用户可见缺陷。
