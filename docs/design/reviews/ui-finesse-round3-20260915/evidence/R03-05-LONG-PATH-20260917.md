- 当前游戏选框、滚动条、Playnite/net462、命令/Binding、取消/错误、恢复保护和有限列表实现均保留。

## 本项实现

- 新增 `PathDisplayConverter` 并注册为 `GscPathDisplayConverter`。长预览用中间省略，保留盘符/根路径开头和文件名尾部；CR/LF 只在预览显示层去除，原始绑定值不改写。
- 新增共享 `GscWpfUiPathDetailTextBox`：只读、`NoWrap`、隐藏内部横向滚动条、保持 WPF 原生选择与 Ctrl+C，并提供完整值 Tooltip/Automation HelpText。固定列使用星号列和 `MinWidth=0`，不会以长文本把详情面板或页面撑宽。
- `DashboardViewModel.CopyPathCommand` 只接收详情绑定的原始路径，直接调用现有 `CopyTextWithRetryAsync(path, ...)`；预览转换器和省略号不会进入复制 payload。空值/空白值不可执行。
- 存档候选、媒体待归类/已归档详情和 Trainer 选中版本路径均提供预览、可选择完整路径框及“复制完整路径”；原有扫描、接受/忽略、媒体操作、工具启动/保存/重新定位命令保持原绑定。
