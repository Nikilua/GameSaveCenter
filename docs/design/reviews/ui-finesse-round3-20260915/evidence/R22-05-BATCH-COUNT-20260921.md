## 现状核对与实现

- 先核对真实批量入口：媒体收件箱已由 R05-04 保留按模式的稳定 ID 选择集合，并能显示总选择数、当前窗口可操作数和暂不可见数；任务中心不是复选选择模型，而是对当前筛选结果生成候选并显示当前结果、可重试数和未纳入原因。本批没有重建这两处已有能力。
- 当前游戏媒体的“收藏所选 / 取消收藏 / 应用当前备注”原先直接使用 `MediaGrid.SelectedItems`，但动作栏没有同时说明当前结果数与跨筛选保留的隐藏选择。本批增加现有动作栏内的实时摘要：已选总数、当前结果数、当前窗口可操作数和暂不可见数；继续复用原 `SelectedItems` 命令参数、ListBox 选框、分页窗口与虚拟化滚动。
- 策略模板批量区继续使用 `PolicyTemplateBatchPreview.Select(PolicyTemplateBatchTargets)` 的显式勾选和稳定 Playnite ID；新增 `PolicyTemplateBatchHiddenSelectedCount`，筛选改变时同步刷新摘要，并在界面同时显示“已选 / 当前结果 / 隐藏选择 / 排除 / 变更字段”。空选择仍明确说明筛选不会自动选择全部，超过 100 个目标仍拒绝执行。
- 任务中心保持“当前结果批量”语义，不伪造一个不存在的复选选择集合；现有 `TaskLoadedSummary`、`TaskActiveFiltersSummary`、当前结果确认和 retryable 计数继续作为该模型的数量证据。没有改变命令绑定、取消/错误语义、恢复保护或 Worker 协议。
