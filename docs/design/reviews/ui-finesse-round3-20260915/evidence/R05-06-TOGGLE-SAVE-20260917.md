## 结论

当前生产设置页的布尔开关已经能在“编辑中的即时显示”“可导出的持久化快照”和“CancelEdit 回滚”之间保持一致；保存状态继续由 R04-08 的稳定提示面表达。当前生产设置没有仅重启生效字段，因此不虚构新的“需重启”状态。

本轮补齐的真实缺口是 `GameSaveCenterSettings` 布尔属性原先多为自动属性，`CopyFrom` 回滚或导入值时不会通知 WPF 绑定，可能让 ToggleSwitch、依赖面板和保存提示停留在旧显示。现在布尔属性使用字段和去重的 `SetBoolean`，值确实变化时发出对应 `PropertyChanged`；未改变值不会重复通知。

`R05TogglePersistenceBehaviorTests.ProductionToggleKeepsValueDisplayAndDraftRollbackAligned` 使用真实 `GameSaveCenterSettingsView`、生产 `ToggleSwitch` 模板、隔离临时目录和 STA WPF `Window`：
