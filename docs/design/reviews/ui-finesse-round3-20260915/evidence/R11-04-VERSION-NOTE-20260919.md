# R11-04 版本说明编辑证据

日期：2026-09-19

分支：`codex/ui-finesse-round2`
范围：版本备注/锁定编辑、取消草稿、重启后读取和稳定 `BackupId`

## 结论

R11-04 已满足当前可控验收条件。

先核对了最新实现：版本说明已经复用 `BackupMetadataUpdateDto`、`LudusaviClient.EditBackupAsync`、Worker 的 `RefreshBackupHistoryAsync` 和 SQLite `backup_versions` upsert；编辑请求只含游戏、`BackupId`、备注和锁定值，不把 `ArchivePath` 或归档文件名作为可编辑字段。本阶段只补齐明确缺口：详情编辑区增加本地“取消修改”命令，回滚到当前 `SelectedBackup` 原值，不发 Worker IPC。

## 实际变更

- `DashboardViewModel` 增加 `CancelBackupMetadataCommand` 和 `HasBackupMetadataChanges`；备注/锁定草稿变更时刷新取消命令状态。
- 取消动作复用已有 `SyncBackupEditor`，只恢复当前 DTO 的备注和锁定状态，清除 dirty 标记并显示“已取消版本备注修改，恢复为原值。”；不会调用 `UpdateBackupMetadata`。
- `SaveCenterView` 版本详情增加“取消修改”按钮，并给备注编辑框、保存/取消动作补充可定位的 Automation 名称；历史表格、游戏选框、滚动条、保存命令和锁定语义保持不变。
- 新增 `R11VersionNoteBehaviorTests`：在真实 `SaveCenterView`/隔离 STA Window 中通过实际绑定的 `ICommand` 探针编辑草稿并取消，验证原备注、锁定状态和稳定 `BackupId` 保持；重复备注的两个版本仍由 `SelectionAnchorResolver` 按 `BackupId` 选中正确对象。
- 新增 Worker 隔离 SQLite 夹具：同一 `BackupId` 更新备注/锁定后重建 `SqliteStateStore`，验证备注可读、锁定保留、`BackupId` 不变，空归档路径更新不会覆盖原 `ArchivePath`。
