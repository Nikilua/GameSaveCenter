# R05-03 弹层边缘适配（2026-09-17）

## 结论

R05-03 在当前可控生产范围内已满足。游戏选框当前是壳层内 Grid，不是独立 WPF Popup；共享 ComboBox 才使用 Popup。游戏选框面板现在按当前壳层可用宽高受限，保留原有选项列表 Auto 滚动。共享 ComboBox Popup 在当前桌面工作区右下边缘实际打开时能翻转回工作区内，最大高度受控，滚动条有效，选定项保持可见。

## 现状核对与边界负例

原生产 `PickerPanel` 固定 `Width=460`、`MaxHeight=500`，在 420×220 隔离壳层中实际工作区只有约 `92 DIP` 宽，面板会越过壳层边界；修复前的边界探针捕获了该负例。修复后面板 `MaxWidth`/`MaxHeight` 绑定 `PickerOverlay.ActualWidth`/`ActualHeight`。由于 420×220 的壳层工作区约为 `92×92 DIP`，搜索框、筛选行和列表无法同时获得有效列表视口；本阶段不把该极端尺寸写成完整可用交互，后续如需支持应先定义壳层最小尺寸或紧凑信息架构。
