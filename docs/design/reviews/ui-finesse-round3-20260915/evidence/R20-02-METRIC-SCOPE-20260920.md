## 1. 任务条件与现有能力

R20-02 要求概览数字显示统计范围和更新时间，区分当前游戏与全库；用户打开数字关联入口后，页面要能说明来源；快照未加载或来源未知时不能把默认值显示成确定的零。

本项先复用现有 `DashboardSnapshotDto` 的 `GeneratedUtc`、全库计数和 `SelectedGame`/任务/最近访问集合，没有改动 DTO、Worker 快照协议或现有选框、滚动条系统。新增的是 `DashboardViewModel` 的显示投影和 `OverviewSnapshotDisplay` 格式化器：

- 全库指标带有“全库 · Playnite 游戏库”和生成时间；当前游戏卡片带有“当前游戏 · 与全库快照同步”和同一更新时间，云端、媒体、最近访问和最近任务继续保留各自已有来源提示或真实命令入口。
- 快照第一次成功返回前，统计值统一显示 `—`，状态说明写明“尚未加载；数字显示 —，不代表 0”；成功快照中的合法零仍显示 `0`，默认 `GeneratedUtc` 仍显示“更新时间未知”。
- 未加载期间隐藏依赖快照状态的比例条和运行状态胶囊，避免 `Worker 异常`、`0` 或空数据被误读为真实状态；成功加载后恢复现有快照绑定和比例计算，零分母的原有隐藏规则保持。
- 当前游戏的版本、媒体、云端和最新备份字段在快照未加载或没有选择时也显示 `—`；选中游戏和快照替换时补发对应属性通知，保持现有命令、绑定和选择语义。
