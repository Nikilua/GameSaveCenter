# R11-03 差异列表搜索证据

日期：2026-09-19
分支：`codex/ui-finesse-round2`
范围：版本差异路径的类型筛选、路径搜索、有限加载和完整路径复制

## 结论

R11-03 已满足当前可控验收条件。

本阶段复用已有 `BackupDiffDto`、`CopyPathCommand` 和 SaveCenter 的有限详情滚动；没有把差异路径写入新存储，也没有改变比较或恢复请求。新增 `BackupDiffPathFilter` 只生成当前比较结果的有界投影：先按新增/修改/删除和不区分大小写的路径片段匹配，再按每类窗口上限显示，剩余结果通过“加载更多差异路径”逐步增加。

## 实际变更

- 比较页增加路径搜索框、类型筛选（全部/新增/修改/删除）和清除筛选入口；三个计数改为当前筛选匹配数。
- 路径结果使用每类有限窗口，初始每类最多显示 `120` 条；匹配总数、当前显示数和是否还有更多单独展示，避免大清单一次性展开。
- 新增、修改、删除路径均使用只读原始文本框，保留完整相对路径可选择内容，并绑定既有 `CopyPathCommand` 逐条复制；显示省略不会进入复制值。
- “未变化”继续单独显示 `UnchangedCount`；非 `Exact` 比较单独提示未知差异质量，不把估算结果伪装成零变化或完整校验。
- 同步修正 R11-02 比较卡片行位：A/B 选择、方向摘要、筛选、计数和有限差异列表各占独立行，未改变页面级滚动系统。
