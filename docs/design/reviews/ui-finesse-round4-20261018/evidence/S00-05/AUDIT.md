# S00-05 上下文预览能力审计

日期：2026-10-22

## 当前能力

- `CommandDirectoryItem` 已固定命令 ID、作用域、真实 `ICommand` 与命令参数，并在转发前复核 `CanExecute`。
- `CommandDirectoryCatalog` 的存档、修改器和媒体入口标为当前游戏作用域，但可用性只检查实时 `dashboard.SelectedGame` 是否为空；任务入口通过 `OpenSelectedTaskGameCommand` 读取实时 `SelectedTask`。
- 命令搜索面板打开时没有捕获当前游戏、任务或工作区。结果行只显示命令名称、分类、作用域和不可用原因，没有显示具体对象。
- 当前目录命令仅导航到工作区、定位设置/搜索、打开游戏选择器或打开任务关联游戏；没有直接作用于备份版本的目录命令，因此不应预览或暗示某个版本会被修改。

## 缺口与实现边界

面板打开后，底层选择或对象列表变化可能使已登记命令改为使用新的实时选择。S00-05 需把预览和执行约束到同一份快照：

- 每次打开时记录工作区、游戏 Playnite ID/名称、任务 ID/类型/关联游戏 ID 与名称。
- 当前游戏入口显示目标工作区与游戏；任务入口显示任务类型与关联游戏；固定导航和全局命令显示其目标工作区或全局范围。
- 游戏或任务选择变化、原对象从集合移除、任务关联游戏变化时，立即禁用对应结果并显示重新选择原因。关闭后重新打开才会捕获新上下文。
- 任务仍须通过现有任务中心、忙碌状态、任务集合和精确游戏 ID 检查；不增加回退到名称匹配的行为。
- 预览只展示当前选择的结果；结果 ListBox 继续使用 Recycling 虚拟化和原有键盘路由。

当前实现可独立完成并受控验证。真实 Playnite 页面交互、物理键盘与 IME 候选仍属于宿主验收，不能由离屏测试代替。
