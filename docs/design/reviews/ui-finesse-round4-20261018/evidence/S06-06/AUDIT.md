# S06-06 失效刷新能力审计

日期：2026-10-21
审计基线：`81ba171c`（含 S06-05 验收 `0aa80547`）

## 计划验收

对象改名、删除、归属变更和权限变化后刷新当前摘要；引用按稳定 ID 解析，不按名称匹配，单条失效不妨碍其他条目浏览。

## 已有能力

- Worker `ResolveWorklistReferencesAsync` 已按对象稳定键精确查询：存档使用游戏 ID+版本 ID，媒体/任务/问题分别按 MediaId、TaskId、FindingId。删除或索引中找不到时返回 `NotFound`；问题解决状态另报 `Resolved`。
- 媒体和校验问题会随当前索引返回父 PlayniteId；任务续接使用当前查到的 ID。刷新按最多 200 条一批查询；请求失败、漏回结果和无法检查不会伪报失效，而显示 `Unavailable`。
- 清单表按每行状态显示有效、失效、无法检查或待刷新；“续接对象”只要求所选这一行可续接。其他条目仍可选择和浏览。没有按对象名称匹配的路径。
- 这些状态只描述 Worker 当前索引。现有提示明确不代表磁盘文件存在或可恢复。

## 尚缺能力

- 查询结果只有对象种类、稳定 ID、引用状态和部分父 PlayniteId；浏览器没有读取或展示当前对象摘要。改名后清单没有可更新的显示名称；媒体/问题归属变更虽然会更新续接使用的 PlayniteId，但清单上不可见。
- 每行 UI 只显示类型、稳定编号、手工状态、备注和索引状态；没有当前摘要字段，因此当前“刷新状态”不等价于刷新对象摘要。
- 查询不会读取真实存档/媒体文件或检查 ACL。清单刻意不保存路径；索引存在不能证明文件可读。Worker 整体查询异常会标为 `Unavailable`，但真实源文件权限变化目前不可辨识，不得把 `Indexed` 表述成“可访问”。

## 结论与准入范围：READY（保持权限边界）

S06-01 至 S06-05 已完成。现有稳定 ID 查询已覆盖删除/索引失效、媒体/问题的归属刷新、不可用状态，以及其他条目继续浏览；缺少的是按 ID 刷新并展示当前索引摘要。

本项补充受限、瞬时的对象摘要：Worker 查询仍按稳定 ID 返回经过长度限制的当前显示摘要和当前父游戏摘要；在清单中更新摘要和归属信息，并提供完整摘要 Tooltip。不要通过名字寻找对象，不持久化摘要、路径、认证或操作令牌；未命中/查询不可用时清空过期摘要并保留条目及其他行的操作能力。测试覆盖改名、删除、归属变化、查询失败与列表继续浏览。

OS 文件 ACL 和物理文件可读性不属于索引摘要的权限：当前无可信宿主权限复核路径，本轮不遍历源路径或改变现有访问边界；界面继续明确此能力未知。此限制需在证据中保留。
