# S06-02 加入待办入口能力审计

日期：2026-10-21  
审计基线：`40a82b15`（S06-01 有界工作清单契约已实现并推送）

## 等价能力核对

- `SaveCenterView` 的版本详情已有恢复、比较和保护操作，但没有“加入人工清单”入口；备份版本稳定身份由 `PlayniteId + BackupId` 组成。
- `MediaCenterView` 有图片比较集合和媒体元数据操作。比较集合只在当前会话存在，最多两张截图，不覆盖视频/任意媒体，也没有人工清单备注或完成状态；媒体项已有 `MediaId`。
- `TaskCenterView` 展示真实后台任务时间线和稳定来源跳转，没有用户维护的人工待办；任务已有 `TaskId`。
- `MaintenanceView` 显示当前问题及来源导航，没有工作清单。Worker 的 `findings` 表已有主键 `finding_id`，但 `ValidationFindingDto` 和查询投影没有暴露该键；可直接复用原持久主键，不按标题或路径合成易变 ID。
- `DashboardViewModel` 已有统一 `StatusMessage` 反馈和 `plugin.ConfirmAsync` 预览/确认 UI；共享资源已有次级动作按钮样式。不需要新后台命令、Worker 授权或专用弹窗。
- S06-01 的 `WorklistDefinition` 已有对象种类、稳定 ID、备注、人工完成标记和有界去重，但尚未接入插件设置或产品入口。

## 缺口与准入结论：READY

没有等价的跨类型人工清单入口。S06-02 计划复用当前详情行，为备份版本、媒体、后台任务和校验问题增加“加入待办”；在确认提示中展示对象类型及可辨识摘要；只在用户确认后把稳定引用加入设置中的当前清单，重复项和容量上限给出明确状态，取消不写入。引用不包含文件路径、运行时 DTO、命令或预览授权，产品业务对象保持不变。

问题项使用现有 `findings.finding_id`，只需在 Contracts DTO 和 Worker 读取投影中透传；如遇到缺失主键，则拒绝加入并说明原因，不回退到标题匹配。S06-03 负责清单浏览/整理，S06-04 负责从已保存清单恢复上下文；本项不声称具备这些能力。真实 Playnite 宿主验收仍单独记录。
