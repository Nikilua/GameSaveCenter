# S03-01 来源关系模型

新增 Core 只读来源模型，按 `BackupId` / `ParentBackupId` 构建明确的父子关系，按内容指纹建立等价关系，并保留每个版本的设备、时间和摘要字段。模型不复制文件清单，也不从时间戳或列表顺序推导父子关系。

重复 ID 会作为冲突组报告；被重复 ID 指向的父版本会标记为歧义，不生成父边。缺失父节点、缺失版本 ID、父链环和未提供父 ID 的未知关系都会成为结构问题。默认最多检查 500 条输入，再读取至多 1 条作为截断探测；相同内容组用代表节点连边，避免成对展开。

## 范围边界
