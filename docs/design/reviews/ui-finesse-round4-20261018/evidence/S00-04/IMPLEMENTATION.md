# S00-04 实现与受控验证

## 实现范围

- 新增 `CommandDirectoryPreferences`，对稳定命令 ID 做规范化、有界保存和未知项清理；最多固定 5 项、最近使用最多 20 项。
- 在插件设置中单独持久化固定/最近命令；不与 `RecentAccess` 游戏历史混用，并接入设置重置、复制和冲突合并。
- 命令成功执行后才记录最近使用；固定/取消固定更新当前目录结果，固定优先、最近次之、其余按目录顺序显示。
- 搜索结果增加固定状态操作与反馈；点击后刷新延后处理，保留路由点击与当前选择状态。
- 保留现有命令、Binding、可用性和错误语义，以及虚拟化列表和键盘访问。
