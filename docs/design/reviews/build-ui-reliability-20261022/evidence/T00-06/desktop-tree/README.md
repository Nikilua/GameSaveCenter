# T00-06 Desktop后代收尾

此前Desktop分支仅调用Process.Kill()，测试中的真实后代断言也只在Core执行。本次Desktop改用Windows taskkill /PID /T /F，根PID来自本次创建且尚未退出的Process对象，不按名称查找或终止。Core仍使用Kill(true)。树终止非零时保留原始诊断并报告失败，即使随后只结束父进程，也不能把未验证的整树收尾吞成成功。

两种PowerShell均实际执行树夹具，并记录子PID加启动时刻；核对同身份子进程已结束、根进程已结束、超时124、无关进程仍存活。原有先写合成TRX再挂起、Unicode、成功重试，以及父进程结束但管道未释放不能报告成功的负例均保留。两份bounded-*.json各有5个实际步骤，不以脚本块文本输出代替执行。

Core7.6.2在沙箱测试通过；Desktop5.1.22000.2538在标准根安装入口相同的非沙箱执行环境通过。初次沙箱执行taskkill退出1，失败摘要与控制台另存；未捕获具体底层原生错误码，不推断失败原因。未改系统权限、未探测CEF/ETW、未结束用户游戏或非所属Worker。
