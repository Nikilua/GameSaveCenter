## 已确认的边界

- 不重写架构，不引入新 UI 框架，不修改 ViewModel、命令、Worker、备份、数据库或其他业务行为。
- 不重复创建第二套 `GlassSurface`、按钮、字体、图标或动效组件。当前 `DesignTokens.xaml`、`Typography.xaml`、`WpfUiProduction.xaml`、`GscIconPack.xaml`、`GscIconButtonPack.xaml` 与 `MotionTokens.xaml` 是既有共享入口；任务应先审计和补齐使用点。
- Demo-first 是视觉主基准。附件中“macOS/Fluent/Mica”只作为材质、层级和可读性质量参考，不能替代当前 Demo 或用户确认的生产视觉。
- 图标按钮仅用于刷新、重试、删除、复制、取消、折叠等低歧义高频上下文操作；扫描、校验、具体打开目标、归类、应用策略和其他有明确后果的动作使用文字按钮。
- 每项保留真实绑定、命令、取消/错误语义、虚拟化、键盘、UI Automation、主题与高对比度回退；不以截图或源码字符串断言代替行为验证。

## 执行规则

1. 按 `U12-00 → U12-02 → U12-01 → U12-03～U12-09` 执行；`U12-10` 贯穿全部阶段。若某项依赖真实宿主，先完成离屏夹具、代码和报告，再标明宿主边界继续下一项。
2. 每项独立提交并 push；提交前运行与改动相称的 XAML、源码、构建、测试、WPF 静态审查和 RenderHarness 门禁。页面布局项必须记录尺寸、主题、数据状态及实际/未实际验证的 DPI。
3. 不把既有 warning/info 当作本轮新增错误；处理 error 级发现。遇到其他人的未提交或已暂存改动，不混入本项提交。
4. 当前旧的 32 项计划继续保留为稳定性、发布和宿主验证历史；本队列是其 UI 后续工作层，优先于其中已过期的视觉改造建议。
